# 🚀 Singularity Engine

> **Графический менеджер серверов и клиентов Space Station 14**  
> Мощное десктопное приложение для Windows, которое автоматизирует установку, сборку и запуск SS14. Создано для того, чтобы избавить вас от рутины командной строки и сделать управление сборками простым, наглядным и безопасным.

## ✨ Основные возможности

### 📦 Управление репозиториями
- Добавляйте, удаляйте, переименовывайте и редактируйте URL репозиториев SS14 (поддержка стандарта и форков).
- Отмечайте любимые сборки звёздочкой — они всегда будут вверху списка.
- Встроенная нормализация URL: случайные дубли и ошибки вставки автоматически исправляются.
- Возможность указать ссылку на готовую сборку (prebuilt) для быстрой установки без компиляции.
- **Выбор корневой папки**: можно указать произвольную директорию для хранения всех сборок.

### 🔧 Установка зависимостей и безопасность
- Автоматическая проверка и установка **Git**, **Python** и **.NET SDK** (9/10).
- Скачивание с проверкой **SHA-256** и **цифровой подписи Authenticode** для защиты от подмены файлов.
- Ручной режим установки с запросом перезагрузки или автоматический фоновый режим.

### 🛠 Клонирование и сборка
- **Git-кэш**: ускоряет повторную установку. При удалении сборки `.git` сохраняется в кэш.
- Поддержка **shallow clone** (мелкое клонирование) для экономии трафика.
- Выполнение скриптов `RUN_THIS.py` или `git submodule update`.
- Автоматическая проверка `global.json`, подбор подходящей версии .NET SDK и проверка целостности проекта.
- Сборка через `dotnet build` с поддержкой многопоточности и предварительного `dotnet restore`.

### 🎮 Запуск игровых экземпляров
- Запуск сервера и клиента одновременно или по отдельности.
- **Автоматическое выделение свободного UDP-порта** для каждого сервера.
- Поддержка нескольких экземпляров одной сборки с настраиваемым лимитом.
- **Диспетчер задач**: мониторинг CPU и RAM для работающих серверов/клиентов в реальном времени.
- Остановка отдельных экземпляров или всех сразу в один клик.

### 📜 Удобная консоль и логирование
- Цветовое выделение логов: системные сообщения, логи сборки, логи конкретного экземпляра.
- Фильтры для быстрого переключения и пакетная обработка для сохранения плавности интерфейса.
- Настройка внешнего вида: шрифт, размер, интервал, перенос строк, цвета фона и текста.
- Быстрое копирование логов в буфер обмена.

### 🔄 Обновление и интерфейс
- **Автообновление менеджера**: проверка свежих релизов на GitHub при запуске (с возможностью тихой установки в фоне).
- **Умная миграция конфигов**: при обновлении ваши настройки сохраняются.
- **Темы оформления**: стандартная, классический терминал, синий неон, фиолетовый киберпанк, красная тревога.
- Кастомные диалоговые окна без рамок и сворачивание в системный трей с всплывающими уведомлениями.

## 🧩 Какие проблемы решает

| Проблема | Решение |
|----------|---------|
| Сложная ручная установка SS14 через командную строку | Вся установка в пару кликов, с автоматической проверкой зависимостей |
| Ошибки при клонировании/сборке из-за несовместимости SDK | Автоматический подбор и установка нужной версии .NET SDK, правка `global.json` |
| Постоянный поиск свободных портов для серверов | Автоматическое выделение и освобождение UDP-портов |
| Невозможность управлять несколькими сборками сразу | Удобный список с избранным, статусами и быстрым запуском |
| Опасность скачивания вредоносных установщиков | Проверка SHA-256 и цифровой подписи Authenticode загружаемых файлов |
| Зависания интерфейса при массовых логах | Фоновые потоки, пакетная обработка логов, ленивые импорты |

- **ОС:** Windows 10/11 (64-bit)
- **ПО (устанавливается менеджером автоматически или вручную):**

## 📥 Установка и быстрый старт

1. Скачайте последнюю версию `SingularityEngine.exe` со страницы [Releases](https://github.com/pirat7770/Singularity-Engine/releases).
2. Запустите файл. *(При запросе разрешите права администратора, если требуется установка зависимостей).*
3. Программа создаст рабочую папку (по умолчанию `%LOCALAPPDATA%\SingularityEngine`).
4. Выберите нужную сборку в списке слева или добавьте свой репозиторий.
5. Нажмите **«Установить»** и дождитесь окончания процесса.
6. Нажмите **«Запустить»** (Сервер, Клиент или оба).

## 🐍 Для разработчиков: Запуск и сборка

### Запуск из исходников

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/pirat7770/Singularity-Engine.git
   cd Singularity-Engine
   ```
2. Создайте и активируйте виртуальное окружение:
   ```bash
   python -m venv .venv
   .venv\Scripts\activate
   ```
3. Установите зависимости:
   ```bash
   python -m pip install psutil pystray Pillow pywinstyles
   ```
4. Запустите приложение:
   ```bash
   python main.py
   ```

### Сборка в .exe

1. Установите PyInstaller:
   ```bash
   python -m pip install pyinstaller psutil pystray Pillow pywinstyles
   ```
2. Выполните скрипт сборки:
   ```powershell
   python -m PyInstaller `
     --onefile `
     --windowed `
     --name SingularityEngine `
     --icon "Singularity-Engine.ico" `
     --add-data "Singularity-Engine.ico;." `
     --add-data "Singularity-Engine2.png;." `
     --hidden-import=psutil `
     --hidden-import=pystray `
     --hidden-import=PIL `
     --hidden-import=pywinstyles `
     --collect-submodules psutil `
     --collect-submodules pystray `
     --collect-submodules PIL `
     --collect-data pywinstyles `
     --clean `
     --noconfirm `
     main.py
   ```
   Готовый исполняемый файл появится в папке `dist/SingularityEngine.exe`.

## ⚙️ Настройки приложения

Настройки доступны по нажатию на значок ⚙ в верхней панели интерфейса.

| Настройка | Описание |
|-----------|----------|
| **Папка сборок** | Путь к корневой папке со сборками (пусто = стандартная в AppData) |
| **Сохранять завершённые экземпляры** | Оставлять записи об остановленных серверах/клиентах для чтения логов |
| **Лимит экземпляров** | Максимальное количество одновременных запусков одной сборки |
| **Авто-удаление при ошибке** | Удалять папку со сборкой, если компиляция завершилась неудачно |
| **Подтверждение очистки / опасных действий** | Показывать диалоги перед удалением кэша, сборок и переустановкой |
| **Мелкое клонирование (shallow clone)** | Использовать `--depth 1` в Git для ускорения загрузки |
| **Параллельная сборка** | Включить многопоточную компиляцию MSBuild (`dotnet build -m`) |
| **Предварительный restore** | Принудительно запускать `dotnet restore` перед сборкой |
| **Строгая проверка SDK** | Запретить автоматическую замену major-версии SDK в `global.json` |
| **Авто-установка зависимостей** | Скачивать и ставить Git/Python/.NET в фоне без вопросов |
| **Требовать цифровую подпись** | Проверять Authenticode перед запуском скачанных установщиков |
| **Сворачивать в трей** | Скрывать окно в системный трей Windows при закрытии крестиком |
| **Сохранять git-кэш** | Кэшировать папку `.git` при удалении сборок |
| **Авто-обновление менеджера** | Скачивать и устанавливать новые версии Singularity Engine в фоне |

## 📁 Структура проекта

```text
Singularity-Engine/
├── main.py                 # Точка входа приложения
├── ui/                     # Графический интерфейс
│   ├── main_window.py      # Главное окно и связка компонентов
│   ├── dialogs.py          # Кастомные диалоговые окна
│   ├── widgets.py          # Уведомления, всплывающие подсказки
│   └── constants.py        # Темы оформления, иконки, статусы
├── core/                   # Основная логика
│   ├── config.py           # Управление конфигурацией (JSON)
│   ├── logger.py           # Система логирования
│   ├── port_allocator.py   # Динамическое выделение UDP-портов
│   └── download_manager.py # Менеджер загрузок с проверкой подписей
├── utils/                  # Вспомогательные скрипты
│   ├── system.py           # Взаимодействие с ОС (процессы, ресурсы)
│   └── updater.py          # Модуль связи с GitHub Releases
├── builds/                 # Папка сборок (создаётся автоматически)
├── logs/                   # Системные логи (создаётся автоматически)
├── config.json             # Файл настроек пользователя (генерируется)
└── requirements.txt        # Список Python-зависимостей
```
