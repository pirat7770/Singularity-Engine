# Singularity Engine

Менеджер сборок Space Station 14 с графическим интерфейсом.  
Позволяет устанавливать, обновлять, удалять и запускать различные сборки SS14, а также управлять активными серверами и клиентами.

## Возможности

- **Установка сборок из Git-репозиториев**  
  Поддержка стандартных репозиториев Space Station 14 и их форков.
- **Git-кэш**  
  Ускоряет повторную установку: при удалении сборки `.git` перемещается в кэш и используется при следующей установке.
- **Запуск сервера и клиента**  
  Автоматический выбор свободного UDP-порта, запуск сервера и клиента с нужными параметрами.
- **Диспетчер активных экземпляров**  
  Отображение CPU и RAM для работающих серверов/клиентов, возможность остановки отдельных экземпляров.
- **Разделение логов**  
  Системные логи, логи конкретной сборки и логи выбранного экземпляра.
- **Сворачивание в трей**  
  При закрытии окна программа может сворачиваться в системный трей (настраивается).
- **Темы оформления**  
  Несколько цветовых схем: стандартная, классический терминал, синий неон, фиолетовый киберпанк, красная тревога.
- **Проверка обновлений программы**  
  При запуске проверяет последний релиз на GitHub и предлагает обновиться.
- **Управление кэшем**  
  Очистка кэша установщиков и git-кэша.
- **Гибкие настройки**  
  Мелкое клонирование, параллельная сборка, предварительный `dotnet restore`, строгая проверка major-версии SDK и другие параметры.

## Системные требования

- Windows 10/11 (64-bit)
- Установленный **Git** (если планируется установка сборок)
- Установленный **Python 3.10+** (для запуска из исходников; для `.exe` не требуется)
- Установленный **.NET SDK 9 или 10** (для сборки; можно установить через программу)

## Быстрый старт (готовый exe)

1. Скачайте `SingularityEngine.exe` из раздела [Releases](https://github.com/pirat7770/Singularity-Engine/releases).
2. Запустите файл.
3. Выберите нужную сборку в списке слева.
4. Нажмите **«Установить»**.
5. После завершения установки нажмите **«Запустить»**.

Программа автоматически загрузит недостающие зависимости (Git, Python, .NET SDK), если это разрешено в настройках.

## Запуск из исходников

1. Клонируйте репозиторий:
  git clone https://github.com/pirat7770/Singularity-Engine.git
  cd Singularity-Engine
   
2. Создайте виртуальное окружение:
   python -m venv .venv
    .venv\Scripts\activate
   
3. Установите зависимости:
   python -m pip install psutil pystray Pillow pywinstyles

4.Запустите программу:
  python main.py

**Сборка из исходников**
1.Установите PyInstaller и зависимости в активное окружение:
  python -m pip install pyinstaller psutil pystray Pillow pywinstyles

2.Выполните сборку:
  python -m PyInstaller \
  --onefile \
  --windowed \
  --name SingularityEngine \
  --icon Singularity-Engine.ico \
  --add-data "Singularity-Engine.ico;." \
  --add-data "Singularity-Engine2.png;." \
  --hidden-import=psutil \
  --hidden-import=pystray \
  --hidden-import=PIL \
  --hidden-import=pywinstyles \
  main.py
